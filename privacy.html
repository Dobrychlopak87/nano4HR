Polityka prywatności – nano4HR

Aplikacja nano4HR (dostępna pod adresem https://dobrychlopak87.github.io/nano4HR/) działa w całości po stronie użytkownika.

  • Nie zbieramy, nie przechowujemy ani nie przesyłamy żadnych danych osobowych na zewnętrzne serwery.
  • Wszystkie dane (wpisy czasu pracy, projekty, ustawienia) przechowywane są wyłącznie w pamięci przeglądarki (IndexedDB) na urządzeniu użytkownika.
  • Aplikacja nie używa plików cookie, Google Analytics ani żadnych mechanizmów śledzących.
  • Funkcja logowania przez Pi Network służy wyłącznie do weryfikacji tożsamości i odbywa się poprzez oficjalne Pi SDK – żadne dane nie są zapisywane po stronie aplikacji.

Kontakt: czernuszewicz.karol@gmail.com.

Privacy Policy – nano4HR

The nano4HR application (available at https://dobrychlopak87.github.io/nano4HR/) runs entirely on the user's side.

  • We do not collect, store, or transmit any personal data to external servers.
  • All data (work time entries, projects, settings) is stored only in the browser's local storage (IndexedDB) on the user's device.
  • The app does not use cookies, Google Analytics, or any tracking mechanisms.
  • The Pi Network login function is used solely for identity verification via the official Pi SDK – no data is stored by the application.

Політика конфіденційності – nano4HR

Додаток nano4HR (доступний за адресою https://dobrychlopak87.github.io/nano4HR/) працює повністю на стороні користувача.

  • Ми не збираємо, не зберігаємо та не передаємо жодних персональних даних на зовнішні сервери.

  • Функція входу через Pi Network використовується тільки для перевірки особи через офіційний Pi SDK – жодні дані не зберігаються додатком.
